GitHub connection

How sign-in works. Git Code Port connects with a fine-grained personal access token that you create yourself and limit to the repositories you choose. The token is sent only to api.github.com. There is no Git Code Port server. A token is a powerful credential: keep its access narrow and its expiry short.

Revoke on GitHub ↗

Disconnect removes the token from this browser. To invalidate it everywhere, also delete it on GitHub.

  1. Open GitHub → New fine-grained token ↗.
  2. Under Repository access, choose Only select repositories and pick the repos you want to save snippets to.
  3. Under Repository permissions, set Contents to Read and write (Metadata: Read-only is added automatically).
  4. Set a short expiration, generate the token, and paste it below.

Defaults

Placeholders: {language} {platform} {host} {yyyy} {mm} {dd}. Examples: {language} → Python/; DSA/{platform} → DSA/LeetCode/ (or DSA/Snippets/ on other sites); Snippets/{host} → Snippets/stackoverflow.com/. Leave empty to save at the repository root. You can always change the folder before pushing.
